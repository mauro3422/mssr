# Provider-refresh

Read when a provider catalog is stale, empty, degraded or replaced.

1. Verify the provider process and exact connected project or application identity.
2. Refresh or reconnect the owning application before editing routing prose.
3. Compare live tools with last-known cached tools and preserve the degradation warning.
4. A new tool with an existing capability shape normally needs discovery refresh and smoke coverage, not a new skill.
5. Change routing only when the capability boundary, activation condition or workflow composition changed materially.
6. Do not let one degraded provider contaminate unrelated route audits or mark unrelated work failed.
