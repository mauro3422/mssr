# Incident-ledger

Read when an observable non-nominal event occurred.

Choose the canonical ledger:

- routing and fixtures: `D:\Dev\mssr\docs\skill-routing\INCIDENTS.md`;
- Bridge tools, transport or lifecycle: `D:\Dev\bridge-mcp\docs\INCIDENTS.md`;
- project-only defects: the project state or incident document;
- procedural skill defects: the owning skill changelog plus the system ledger when relevant.

Record date/status, layer/owner, symptom, minimum reproduction or exact evidence, demonstrated cause or `No resuelta`, correction, regression and follow-up. Never store raw prompts, transcripts, secrets or private reasoning.
