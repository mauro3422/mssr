# MSSR project state

## Current release
MSSR source release is `0.2.7`. The portable closure evaluator now exposes explicit required-skill, verification, persistence, close, maintenance, and outcome obligations; it rejects `success` while an applicable gate is pending without coupling the core to Bridge or a host. The portable change-history/knowledge-impact contract, learning rollout documentation, versioned changelog structure, and modular project authorities remain implemented. `npm run verify` and the cross-repository source maintenance gate pass; publication remains separate.

## Learning dataset state
Strict `learning-digest-v1` collection remains active through Bridge in `observe-only` mode with `routingInfluence=false`. Historical priors are metrics only. Current work adds dataset-quality/replay/calibration/shadow activation gates and project change-history evidence; no learned score is consumed by routing or context selection.

## Core skill package state

The first-party MSSR skill package is roadmap work, not yet migrated. Existing MSSR operational skills still live in the external custom skill catalog/runtime junctions and require an ownership/audit pass before moving.
