# Synthetic MSSR Librarian Fixture v1

This file is an invented test fixture. It is not project policy, a real MSSR source, or human owner-gold.

## Authority and contradiction handling

The repository owner retains final authority over canonical project knowledge. The Librarian may surface conflicting passages, but it must preserve their provenance and present the conflict for review. Jev can select among bounded evidence candidates; it cannot decide which source is canonical or write a canonical replacement.

## Exact citation retrieval

Before relying on a Librarian citation, the host must fetch the exact revision-bound source range and verify that the evidence pack binds to the same source, revision, and range. A search result or a Jev selection handle alone does not prove that the cited text supports the answer.

## Confidence and sample-size limits

Jev confidence is descriptive and uncalibrated; it is not a guarantee of correctness or authority. This fixture gives no numeric confidence threshold for production use. Any project threshold must be owned by the project and evaluated against independently labeled cases. The fixture specifies no exact number of owner-gold labels needed to calibrate such a threshold.
