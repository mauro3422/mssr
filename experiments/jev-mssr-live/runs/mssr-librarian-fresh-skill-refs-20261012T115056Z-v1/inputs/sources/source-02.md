# Routing-edit

Read when activation, phase, dependency, exclusion or composition changes.

1. Read the current skill completely and identify the Git source of truth.
2. Use `skill-routing-maintainer`; inspect vocabulary before writing structured metadata.
3. Update the versioned routing contract, never generated dashboard copies.
4. Add a positive fixture, nearby negative fixture and continuation fixture for resumable workflows.
5. Verify active and deferred skills; a useless deferred skill is still routing contamination.
6. Run `skill_route_audit`, representative real route plans and the full MSSR verification gate.
7. Record the observable incident in the canonical routing ledger when correcting a false positive, false negative or contract defect.
