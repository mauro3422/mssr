# Host-assembled answer

The model has three layers. **Layer 1 (atomic component)** consists of small reusable pieces with stable local interfaces that remain independent from the device shell (docs/ELECTRONICS_MODULAR_SYSTEM.md:L28-L42). **Layer 2 (functional module)** is a bounded assembly that combines atomic components for one purpose (docs/ELECTRONICS_MODULAR_SYSTEM.md:L45); it owns their placement while preserving source lineage and detachable identity when repair may expose them (docs/ELECTRONICS_MODULAR_SYSTEM.md:L55). **Layer 3 (serviceable assembly)** defines the device-specific interior and shell, including module mounts, cable routing, and removal order; it decides which reusable pieces to instantiate and which device-specific geometry to create (docs/ELECTRONICS_MODULAR_SYSTEM.md:L57-L70).
