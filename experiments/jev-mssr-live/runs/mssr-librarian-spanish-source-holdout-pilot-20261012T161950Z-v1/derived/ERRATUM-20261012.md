# Run 59 erratum — empty search invoked implicit heading selection

Date: 2026-10-12. This correction supersedes the earlier version of this erratum.

The raw Run59 records show two cases where search returned zero results:

| Case | Label | Search results | Jev candidates | Jev result |
|---|---|---:|---:|---|
| `farm-real-days-negative-es` | unanswerable | 0 | 7 | abstained |
| `zomboid-watch-loss-result-es` | answerable | 0 | 9 | abstained |

The frozen runner omitted `candidateHandles` when the search result list was empty. The selector treats an omitted field as its alternate implicit-heading mode, so Jev received every eligible heading in the supplied document. In the Zomboid case, Jev returned `none` with 1,842 input tokens and 134 output tokens; no range was selected, fetched, or packed.

Correct interpretation: both search misses remain valid retrieval observations. The two final abstentions are not zero-candidate tests and do not prove how Jev behaves when the Librarian gives it an empty search pool. Run59 mixes search-conditioned selection with implicit whole-document heading selection in those two cases. Its 2/3 positive selections, 3/3 negative abstentions, search recall 2/3, exact range 1/3, and fetch/pack 2/2 remain descriptive of the recorded calls, but the mode mixture must be considered when interpreting the selection metrics.

The reusable runner template now skips Jev when no search handles exist and records `status: not-run`, `reason: no-search-candidates`, `candidateCount: 0`, and `jevCallMade: false`. A regression covers this path. The frozen Run59 manifest, input, labels, provider records, and original checksums were not changed; only derived interpretation is corrected.

Metric naming caveat: the legacy `summary.json` field `exactHeadingMatches` is computed from exact accepted line-range bounds, not just a matching heading title. The derived summary separates normalized heading matches (2/3) from exact accepted ranges (1/3); use the latter when discussing exact span precision.

The packet does not include the supporting inventory/reviewer artifact needed to reproduce the claimed 85-document/160-snapshot novelty audit or the independent blind-review judgments. Treat those as reported upstream evidence, not independently verified by this packet.
