# 0.2.44 — 2026-08-18

- Summary: Harden portable trace closure projection after the 0.2.43 post-release audit: a persisted outcome on a closed trace now remains observably complete instead of regressing to pending, while `canCloseSuccess` stays a prospective pre-outcome gate.
- Areas: trace-contract, observability, lifecycle-integrity, project-context, testing, documentation
- PROJECT_CONTEXT: updated
- PROJECT_MEMORY: updated
- PROJECT_STATE: updated

## Changes

- Fixed `evaluateMssrRouteClosureObligations(...)`: the outcome obligation now projects `complete` once the shared lifecycle reducer has closed the trace on an accepted outcome checkpoint. Before outcome, the same obligation remains `ready` only when all required preconditions are complete.
- Preserved `canCloseSuccess` as prospective preflight metadata rather than a historical completion flag. A closed trace therefore reports `canCloseSuccess=false`, `outcome=complete`, and `nextRequiredAction=none` without contradictory status.
- Added an exact pure-contract regression in `test-trace-contract.mjs` that reduces a real outcome checkpoint and verifies closed-state closure projection.
- Added a Codex standalone regression proving the same post-outcome `complete` state through the host-neutral adapter surface.
- Updated `docs/AGENT_PROTOCOL.md` to distinguish prospective `ready/canCloseSuccess` semantics from persisted post-outcome `complete` semantics.
- Added indexed durable project memory `mssr-trace-lifecycle-integrity` under `.mssr/knowledge/decision/trace-lifecycle-integrity.md`. It also records the ownership boundary discovered by the same audit: project/workflow identity belongs to logical trace identity, while host adapters own session/project attribution and recovery.
- Added Trace Integrity Hardening to ROADMAP and closed only the portable closure-projection sub-slice. The sibling Bridge attribution bug remains explicitly pending and must be fixed under the Bridge project owner with a two-project regression before learning data is trusted further.
- Source version moves to `0.2.44`. This release does not adopt a new MSSR package in Bridge and does not modify host trace attribution.
