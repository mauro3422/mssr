## Changes

- Added strict schemas for bounded context messages, evidence references, provenance/freshness, continuation receipts and review-only persistence proposals. Raw prompts, transcripts, secrets, arbitrary tool output and private reasoning are outside the contract.
- Added deterministic intent/stage selection, priority, dedupe, character/message budgets, required-message accounting and observable hard-cap overflow.
- Added identical portable selection output to native MCP routing and Codex/OpenCode route/bootstrap adapters without adding I/O, mutation authority or host queues.
- Added golden cross-host fixtures for selected IDs, decisions, receipts, advisory-only behavior and strict rejection of unknown fields.
- Added the Context Plane v1 ADR and updated architecture, project context, observatory, roadmap and agent protocol documentation.
- Updated the first-party routing and maintenance skills so agents validate canonical owner, provenance and freshness, re-plan on uncertain evidence, and review persistence proposals before changing repository authorities.
- Bridge `0.6.89` is a separate source adapter release that can piggyback selected messages as notices. Its runtime remains `0.6.88` until controlled publication, restart and live readback; this release does not claim a durable inbox or real ChatGPT Web parity.

- `npm run verify` remains the complete source gate, including first-party skill packaging and routing audit.
