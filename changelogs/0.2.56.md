# 0.2.56 — 2026-08-22

- Summary: Make Context Message selection budget the exact structured message size instead of trusting an optimistic producer hint.
- Areas: Context Plane, context messages, host envelopes, verification
- PROJECT_CONTEXT: updated
- PROJECT_MEMORY: updated
- PROJECT_STATE: updated

## Changes

- Treats `estimatedChars` as a lower-bound hint. Selection budgets, hard caps, overflow evidence and decisions now use the greater of the declared hint and the exact serialized structured message size.
- Makes first-party repository producers report a measured estimate when it fits the existing public 2,000-character hint field.
- Prevents accumulated historical changelog messages with legacy `estimatedChars=320` from consuming many times their declared budget in a host response.
- Preserves required-message overflow semantics and advisory-only behavior; no message, receipt or proposal gains mutation authority.

## Verification

- Context Message selection, producer and repository-provider regressions — PASS.
- Added an explicit underestimated-message regression proving a message cannot fit a budget smaller than its serialized form.
- Full `npm run verify` and `npm run release:gate` — required before publication.

## Project knowledge impact

- PROJECT_CONTEXT: updated to define serialized-size accounting as the portable Context Message budget contract.
- PROJECT_MEMORY: updated with the rule that caller estimates may reserve more but never less than materialized bytes.
- PROJECT_STATE: updated with the 0.2.56 release/adoption state.
