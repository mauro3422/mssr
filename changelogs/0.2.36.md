# 0.2.36 — 2026-08-18

- Summary: Add Situation Model C2f-C.5-A/B as the first portable Architecture Impact Map / Structural Fingerprint slices. MSSR can now determine which declared architecture decisions surround exact files before an edit occurs, refine those coarse relations without widening authority, and fingerprint sparse stable Markdown architecture sections so unrelated document edits do not automatically become architecture-impact evidence.

## Changes

- Added pure `findArchitectureImpactForTouchedRefs(...)` reverse lookup over the reviewed C2f-A manifest. Exact touched refs map to every matching declared architecture in manifest order, including `authorityRef`, optional `contextRef`, and authority-vs-impact role; no hash/revision change is required.
- Added optional `.mssr/architecture-structure.json` plus `src/architecture-impact-structure.ts` and strict host-neutral JSON Schema. The structural manifest may refine only existing declared architectures and impact refs; unknown architectures or undeclared implementation refs fail rather than silently widening authority.
- Structural entries can name sparse Markdown authority anchors and bounded TypeScript/JavaScript symbol selectors (`signature`, `body`, `shape`). Symbol selectors are declaration only in A/B: no AST evidence, parser result, inferred link, or architecture claim is synthesized yet; C2f-C.5-C owns the host-neutral analyzer boundary.
- Added `findArchitectureTouchContext(...)`, which combines coarse pre-edit awareness with optional structural refinement while preserving every coarse match. A shared file such as `src/project-home.ts` therefore remains related to both `architecture-impact-plane` and `project-context-plane` even when no selector is declared for that exact file.
- Added `src/architecture-markdown.ts` with sparse explicit `<!-- mssr-arch-anchor: ... -->` markers attached to headings, fenced-code awareness, duplicate/orphan rejection, bounded section extraction, newline/trailing-whitespace normalization, and deterministic length-prefixed SHA-256 section fingerprints.
- Markdown section fingerprints intentionally exclude the root heading text and anchor marker. Renaming the heading while preserving the stable anchor/body remains aligned; body or nested-subsection changes alter the fingerprint; changes after the section boundary do not.
- Self-hosted ADR 0005 now declares `impact-relation-meaning`, `impact-ownership`, and `impact-structural-map`; ADR 0001 declares `context-plane-ownership`. The repository self-hosted structure manifest links only these sparse landmarks and a small set of important implementation symbol selectors rather than every paragraph/function.
- Extended MSSR project-home control-file vocabulary with `.mssr/architecture-structure.json` and updated the self-hosted `architecture-impact-plane` source set to include the new portable modules/schema/manifest.
- Updated ADR 0005 and ROADMAP to insert C2f-C.5 before C2f-D. C2f-C.5-C remains the portable/host-neutral code-symbol structural analyzer gate; Bridge-only `analyze_code`/`impact_analysis`/dependency tools are not portable authority. C2f-C.5-D remains derived graph candidates plus executable architecture invariants.
- Added `scripts/test-architecture-impact-structure.mjs` and `test:architecture-impact-structure` to the aggregate test chain.
- Source version moved to `0.2.36` with no new MCP tool and no Bridge adoption.
