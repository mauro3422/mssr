## Behavior

- Search accepts up to four optional `queryVariants`, each at most 500 characters and 2,000 total characters. Variants must contain searchable terms and be distinct from the primary query and each other after normalization.
- Omitting variants preserves current search results and ranking. With variants, primary-query matches rank first; variant-only results follow in supplied order. Each result identifies its score query index and per-query matched terms. No cross-query score aggregation or confidence interpretation is introduced.
- Exact handles remain bound only to owner, source, revision, range, fingerprint and privacy class. Variant text does not alter handle identity. Typed metadata-projection matches report query lineage, and structured metadata filters retain exact-match behavior.
- The calling host owns translation and variant generation. This release does not update or deploy any Bridge runtime.
