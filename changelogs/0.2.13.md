## Changes

- **Domain metadata** (`config/skill-routing/skill-routing-overrides.json`): `godot-graph-ux-audit.domains` collapses from `["godot", "coding"]` to `["godot"]`. Together with the pre-existing scorer gate at `scoreEntry`, a non-Godot acceptance/architecture verify no longer selects the Godot graph or inspection skills.
- **Fixtures** (`config/skill-routing/skill-routing-fixtures.json`): `architecture-verify-excludes-godot` asserts the generic repo-architecture verify route excludes all four Godot skills; `godot-graph-ux-audit-verify` asserts the Godot graph verify route conserves `godot-project-inspection` plus `godot-graph-ux-audit`.
- **Host-gated regression test** (`scripts/test-skill-routing.mjs`): the optional-dependency route intent now targets the Godot graph editor so graph+inspection are selected on a real Godot task while the host-gated optionality contract is preserved.
- **Complex system design routing** (`config/skill-routing/skill-routing-overrides.json`): `complex-system-design` is explicit and cross-domain but requires the `design` action plus an artifact match; ordinary `analyze/debug/test` coding does not activate it.
- **Complex system fixtures** (`config/skill-routing/skill-routing-fixtures.json`): adds greenfield-design, repeated-patch reset, nearby small-specified-feature negative, and continuation-to-next-fixture cases. The generic TypeScript fallback regression remains unchanged and proves the new skill does not occupy verification accidentally.
