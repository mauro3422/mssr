## Changes

- Adds `planArchitectureHostAdoption(...)`: exact touched refs select only already-declared affected architectures and their existing C2f-B observation plans; unrelated refs remain inert and shared refs preserve multiple declared architectures.
- Adds `evaluateArchitectureHostAdoption(...)`: host-supplied evidence is normalized and passed through existing C2f-C projection, C2f-E reviewed-current evaluation, and C2f-D natural-replan feedback rather than duplicating those decisions in adapters.
- Fixes the portable boundary as `semanticOwner=mssr`, `hostOwnsObservation=true`, `canonicalRewriteAllowed=false`, and `advisoryOnly=true`; the new coordinator performs no filesystem I/O, watcher scheduling, context autoload, semantic retrieval rerun, or canonical architecture mutation.
- An exact reviewed-current receipt suppresses repeated review/replan/context feedback while preserving the underlying `possible-impact` projection as evidence.
- Adds a strict TypeScript/Zod contract, JSON schema, focused regression suite, public export, self-hosted Architecture Impact relation, ADR/decision documentation, and roadmap decomposition for later structural evidence plus native/Codex/OpenCode/Bridge adoption.
- Reconciles stale roadmap/state facts: Bridge trace attribution was completed in 0.6.109/0.6.110, and Bridge 0.6.110 consumes exact MSSR 0.2.45; package parity is explicitly not treated as proof of Architecture Impact lifecycle adoption.
