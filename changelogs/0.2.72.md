## Changes

- Extend `evaluateMssrSemanticConsistency` with relation-aware comparison. Same-subject claims still flow through Situation/C2c; current declared `mirrors`/`summarizes` relations may compare differently named subjects of the same claim kind. Derived relations never become deterministic truth.
- Add explicit unresolved relation evidence for missing declared target subjects/refs, including required lifecycle targets for `produces`/`consumes`/`adopts`/`implements`.
- Add bounded semantic candidate retrieval with authority order `declared relation -> same subject -> exact ref -> TF-IDF`. Every lexical/derived candidate is `CANDIDATE`, `truthAuthority=false`, and cannot enter the contradiction evaluator merely because similarity is high.
- Add production `roadmap-contradiction` and `unresolved-reference` Context Message producers. Only PROVEN current roadmap conflicts or explicit unresolved declared relations emit these messages; dedupe identity is stable and resolved evidence becomes silent.
- Add a strict optional shadow-model observation contract. Host-supplied NLI/cross-encoder output is permanently normalized as `derived`/`candidate` with `routingInfluence=false`, `truthAuthority=false`, `directNoticeAuthority=false`, and `canonicalRewriteAllowed=false` unless a future reviewed contract explicitly changes that boundary.
- Extend the shared host-conformance surface with identical native/Codex/OpenCode tools for semantic evaluation, candidate retrieval, Context Message production and shadow classification. These tools are I/O-free; hosts still own observation, transport and persistence.
- Update the R4 coverage inventory so real Context Message producers are no longer reported as reserved while separate Bridge package/runtime adoption remains `pending-adoption`.
- Reconcile current durable project state with verified host reality: Bridge `0.6.139` consumes MSSR `0.2.71`; `0.2.72` host adoption remains a separate gate and is not inferred from source parity.
- Keep R4 detail in two bounded selective modules (`mssr-semantic-consistency-decision` for current truth and `mssr-semantic-relations-retrieval-decision` for relation/retrieval/message/shadow policy), restoring Project Context Health to `ok` without budget inflation.
