## Changes

- Add ADR 0006, `Deterministic semantic/document consistency`, which keeps contradiction handling inside the existing Situation Model/C2c/C2d ownership stack. Declared identity/ownership plus deterministic typed claims and temporal/scope/authority constraints may prove bounded conflicts; similarity, embeddings/vector retrieval, fuzzy text matching and future NLI are candidate/review evidence only and never truth, routing, notice-severity or write authority.
- Record the integration audit rather than treating exports/tests/roadmap checkboxes as runtime adoption. The audit confirms that C2e-D semantic claim producers are public/tested but have no production host producer, Document Freshness 0.2.66 has no live host consumer yet, several Context Message kinds have no first-party producer, and bootstrap/context ceremony remains an explicit optimization debt.
- Reopen trace-owner isolation after observing one explicit `traceId` acquire multiple projects/workflow keys across project switching. Cross-project traces must remain separate until the host recovery/attribution regression is fixed and verified.
- Correct ROADMAP truth for Document Freshness: the portable 0.2.66 evaluator/manifest contract is complete, while Bridge adoption remains a separate pending host integration gate rather than an already-live capability.
- Narrow `evaluateMssrProjectKnowledgeMaintenance(...)` routing-change detection to actual semantic owner paths (`config/skill-routing/**`, `src/skill-routing.ts`, `src/intent-normalizer.ts`). Documentation such as `docs/skill-routing/INCIDENTS.md` no longer raises `routing-contract-changed` merely because of its pathname.
- Add focused regression coverage proving documentation-only `skill-routing` paths remain outside skill-maintenance debt while the canonical routing source still raises the expected routing target.
- Update PROJECT_CONTEXT with the retrieval-vs-claim-vs-contradiction boundary, the indexed drift-review memory with the integration-chain and abstention rule, and PROJECT_STATE with current release/adoption truth. No detector or similarity mechanism receives canonical rewrite authority.
