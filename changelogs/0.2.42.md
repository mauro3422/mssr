# 0.2.42 — 2026-08-18

- Summary: Complete Situation Model C2f-D with bounded Architecture Impact context feedback that reuses C2e-E exact project-context resolution only at natural MSSR replans, without semantic retrieval reruns, silent auto-loads, budget overrides, or per-tool-response injection.
- Areas: situation-model, architecture-impact, context-plane, project-context, testing, documentation
- PROJECT_CONTEXT: updated
- PROJECT_MEMORY: updated
- PROJECT_STATE: updated

## Changes

- Added `src/architecture-context-feedback.ts` as a pure portable adapter from an Architecture Impact projection to the existing C2e-E context-request contract.
- Active REVIEW emits at most two advisory requests for the matching architecture: the exact declared `contextRef` when present plus the declared architecture authority/ADR. Aligned architecture emits no request.
- Feedback is explicitly `trigger=natural-replan`, `replanOnly=true`, `semanticRetrievalRerun=false`, `autoLoad=false`, `budgetOverride=false`, `selectionPolicy=normal-budgeted-selection`, and `advisoryOnly=true`; nested requests remain `required=false`.
- Refactored `src/situation-context-feedback.ts` to expose exact reusable `resolveMssrSituationContextAuthorityRef(...)` and `resolveMssrSituationContextEntryId(...)` helpers without changing C2e-E selection semantics.
- Added strict `architecture-context-feedback.schema.json`, public exports, focused tests and aggregate-suite coverage.
- MSSR self-hosts C2f-D: its real Architecture Impact and project-context manifests resolve `architecture-impact-plane` REVIEW to exact context entry `mssr-architecture-impact-decision` plus ADR 0005 as canonical authority; no semantic search or invented indexed ADR entry occurs.
- Added the C2f-D module/schema to the declared Architecture Impact relationship and sparse structure manifest.
- Updated ROADMAP, ADR 0005, PROJECT_CONTEXT and PROJECT_MEMORY. C2f-E reviewed-current receipts remain separate and pending.
- Source version moves to `0.2.42`. No new MCP tool, queue, watcher, automatic context load, architecture rewrite, or Bridge adoption is part of this release.
