## Changes

- Added `src/situation-model.ts` with bounded evidence classes `observed` / `declared` / `inferred` / `learned`, project-knowledge categories, notice classes and `evaluateMssrSituationModel` composition over C2c+C2d.
- Evidence reliability and semantic authority are orthogonal. `inferred`/`learned` evidence cannot declare canonical authority; confidence metadata cannot override source-of-truth ownership.
- Added revision-first project-knowledge normalization: current repository observations provide canonical revisions while selected Context Messages and durable delivery receipts provide historical revisions. Revision disagreement can prove stale agent context without interpreting PROJECT_MEMORY/ADR prose; only the newest receipt per authority participates and a current selection supersedes older receipts so refresh can resolve the mismatch cleanly.
- `loadProjectContextHost` now returns a bounded `situation` snapshot in addition to existing projectContext/contextMessages/inbox/repository output, without changing selection or persistence authority.
- Added notice classification metadata (`category`, `noticeClass`, bounded priority) while retaining the existing `ok/watch/review/error` attention scale rather than creating a competing severity system.
- Added `scripts/test-situation-model.mjs`, ADR 0004 and roadmap C2e-A/B/C/D/E gates. C2e-C host watcher adoption is separate from this portable release.
