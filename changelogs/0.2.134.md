## Behavior

- Apply the local privacy preflight to semantic curation, Librarian selection, and semantic relation review.
- Replace path-shaped owner/source/project/corpus identifiers with request-local opaque labels before transport; retain original identifiers in local exact-source results.
- Block private/non-public IPv4 addresses, remaining Windows/UNC paths, and common credential/token patterns in query or evidence content. Diagnostics report categories/counts only and never echo matched text.
- Prepare and screen all independent curation/relation batches before starting concurrent provider calls, so one blocked request prevents partial disclosure from its sibling batches.
- This is narrow deterministic defense in depth, not comprehensive DLP, authenticated privacy classification, or authorization. Host privacy labels and provider policy remain required.
