## Changes

- Added `evaluateMssrInfrastructureOperationalAttention` with independent tunnel, runtime continuity, restart, and transport dimensions.
- A lost/upstream response by itself is `WATCH`; a lost response plus independently observed runtime restart is `REVIEW`; unavailable tunnel/runtime or failed restart is `ERROR`.
- Added `evaluateMssrProviderOperationalAttention`, keeping provider/catalog availability separate from target continuity/readiness.
- Healthy-provider target warming/inactive states stay quiet `WATCH`; ambiguous/missing/inspection-failed targets become `REVIEW`; an unavailable provider becomes `ERROR`.
- Operational fingerprints remain semantic and exclude timestamps, PID, boot UUIDs, request text, prompts, and other volatile host metadata.
- Added incident-shaped regressions for response loss with stable runtime, response loss across restart, pending restart, tunnel failure, provider degradation/unavailability, target loss/ambiguity, stable fingerprints, and explicit resolution.
- Split Operational Notice Plane gate C2 into C2a (provider/infrastructure) and C2b (routing compliance) so this release does not claim the remaining routing producer is complete.
