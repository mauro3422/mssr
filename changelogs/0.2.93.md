## Portable implementation

- Librarian retrieval searches caller-supplied Markdown and returns candidate handles bound to source ref/revision, exact range, fingerprint, owner and privacy label. It caps documents, characters, lines, headings, catalog records, ranges, candidates, results, snippets and fetch size. MCP search/fetch tools operate only on documents supplied by the caller; they do not scan a filesystem or provide a global index.
- Owner, privacy and catalog namespace/kind/provenance are caller-supplied assertions. Retrieval candidates do not authenticate a producer, prove truth or authorize reading/writing. Free-form catalog metadata is not copied into results.
- Semantic judgments bind selected-option confidence, optional provider-returned distributions and relation citations to exact EvidenceAtom identities and source revisions. They validate coverage, temporal/scope consistency, relation/head agreement, content-addressed identity and explicit verifier subject/provider/trace independence.
- A Jev relation-review MCP tool batches compatible pairs within one explicit project/corpus scope, injects host-owned Jev transport, preserves raw selected-option confidence without inventing a full class distribution, and returns each judgment as unverified. A separate MCP tool creates exact-text synthesis previews; neither writes project sources.
- Synthesis proposals revalidate source handles and payload fingerprints, retain exact source snapshots and are immutable/reversible. Disjoint evidence components are kept in separate Jev requests; connected pairs may be batched under limits. Only comparable support/duplicate edges above an explicitly uncalibrated raw-confidence gate and caller-supplied independent-confirmation evidence can be preview candidates. Unknown/non-fresh source classifications, contradictions, unresolved/incomparable edges, and unverified judgments remain review-only or separate. The response marks verification/freshness assertions as caller-supplied and requires the host to re-read current revisions before consuming a candidate. MCP integration tests exercise search, exact fetch, Jev review and preview with a fake injected transport. No apply/canonical-write authority is introduced.
- Research documents public Jev/OpenAI/Reddit/Doom evidence with source-quality limitations, the preserved QuietDesk run boundary, and 100 unvalidated use-case hypotheses. Jev decisions are documented as one component in composed grep/selection/compaction/generation/action/verifier workflows; no task capability is attributed to Jev alone.
