## Changes

- Added `src/architecture-symbol-analysis.ts` with a strict v1 host-neutral contract for code-symbol analysis.
- `planArchitectureSymbolAnalysis(...)` emits one deterministic plan per implementation target already reviewed into `.mssr/architecture-structure.json`; it performs no filesystem read, AST invocation, graph inference, or context loading.
- Host evidence is bound to an explicit `sourceRevision`, `analyzerId`, and separately versioned `fingerprintScheme`. Analyzer identity therefore never implies fingerprint comparability.
- Each declared selector must produce exactly one explicit `observed`, `missing`, or `unavailable` result. Observed results carry a bounded SHA-256 structural fingerprint and optional source location; unavailable results may carry a bounded analyzer-local reason code.
- `normalizeArchitectureSymbolAnalysisEvidence(...)` restores declaration order and rejects duplicate, extra, omitted, or undeclared selector/target evidence rather than widening reviewed architecture authority.
- `analyzeArchitectureStructureManifest(...)` executes one host-owned callback per declared target. Exceptions propagate immediately; portable MSSR performs no retry and synthesizes no replacement evidence.
- Added strict `config/project-context/architecture-impact-symbol-analysis.schema.json` for host interchange. Zod remains responsible for relational invariants that plain JSON Schema cannot express directly, such as duplicate selector keys and reversed source ranges.
- The repository self-hosts C1: `architecture-impact-plane` declares the new module/schema as impact refs and `.mssr/architecture-structure.json` declares important C1 function surfaces.
- Split the remaining code-symbol gate into C1 contract, C2 portable/reference TypeScript/JavaScript analyzer implementation, and C3 reviewed structural-baseline comparison/refinement. Whole C2f-C.5-C remains open until C2/C3 close.
- C1 does not refine C2f-C `possible-impact`, emit notices, request context, persist reviewed-current receipts, infer import/call/dependency relationships, or auto-update ADR/context truth.
- Source version moved to `0.2.37` with no new MCP tool and no Bridge adoption.
