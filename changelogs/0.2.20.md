## Changes

- Added `src/operational-projections.ts` with deterministic portable evidence identities.
- Trace idle is advisory-only: an open routed trace observed idle can reach `REVIEW`, but silence never proves completion, synthesizes an outcome, or becomes `ERROR` by itself.
- Project-knowledge maintenance now projects `review -> REVIEW` and `required -> ERROR`, remains actionable while the current lifecycle revision has unresolved maintenance debt, resolves after a fresh close+maintenance revision, and can reopen after later invalidation.
- Context Plane freshness now projects `fresh -> OK`, unknown-only -> `WATCH`, stale/unavailable -> `REVIEW`, and conflicting identity/provenance/reference evidence -> `ERROR`.
- Operational fingerprints exclude volatile host timing/activity counters so stable debt stays quiet while meaningful evidence changes remain observable.
- Added projection regressions to the Operational Notice Plane test suite and split roadmap gate C into completed C1 plus pending provider/runtime/routing C2.
