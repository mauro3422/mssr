## Librarian Jev selection

- Add `mssr_librarian_jev_select` to the existing semantic-evidence MCP registration; reuse Document Surface ranges, provider contracts and exact Librarian fetch handles instead of duplicating retrieval infrastructure.
- The caller supplies Markdown snapshots and the query. The tool offers up to 254 eligible heading sections plus `none` to one Jev Choice request, excludes `sensitive-excluded` sources, and returns only an advisory revision-bound handle. The caller must fetch the selected range against the current source snapshot.
- Per-option and aggregate context limits reject oversized selections as `not-run` without calling Jev or silently truncating the candidate set. Search remains lexical and deterministic; the Jev path runs only when a caller explicitly invokes the separate tool.
- Provider-reported confidence is explicitly uncalibrated. Titles, paths and excerpts are JSON-encoded untrusted document data. Owner, path and privacy labels remain caller assertions. The selector grants no source authorization, truth, verification, compaction, paragraph generation or write authority.

## Live integration evidence and limits

- The compiled MCP registration was exercised through an in-memory MCP client/server with the real TypeSafe Jev provider and the existing Windows Credential Manager entry. One Spanish query was sent with the frozen 21-document MSSR corpus (200 heading candidates plus `none`). Jev selected the benchmark target “Evidence atom and source boundary” in `.mssr/knowledge/architecture/semantic-evidence-plane.md`; the exact follow-up fetch matched its revision-bound fingerprint. Checksummed evidence: `experiments/jev-mssr-live/runs/mssr-librarian-jev-mcp-selector-smoke-20260930-v1/`.
- The single call used 18,192 input and 2,027 output tokens, reported confidence 0.79 (uncalibrated), and took 5,670.1 ms. The matching target label came from Luna double-review, not human document-owner adjudication. This confirms MCP/provider/fetch wiring for one case; it does not establish retrieval quality, calibration, broad semantic accuracy, paragraph synthesis or production host adoption.
