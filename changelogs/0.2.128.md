## Behavior

- Coalesce repeated exact evidence handles before applying the retrieval result limit, including duplicate document snapshots whose source refs normalize to the same value.
- Allow `candidateHandles: []` only as an explicit `selectionMode: "search-results"` result. Return `not-run` with `no-search-candidates` and make no Jev call.
- Require `selectionMode: "all-headings"` when a caller intentionally asks the selector to enumerate headings. Reject omitted/ambiguous mode so an empty search cannot silently become a heading search.
- Accept bounded explicit `queryVariants` in selection and use them only when centering excerpts. Keep the original query unchanged in the Jev decision request.
- Add deterministic regressions for normalized duplicate refs/top-k, fail-closed empty pools, explicit heading mode, and bilingual retrieval where the matching evidence appears near the end of a long block.
- Update the architecture contract, ADR 0009 and the MCP tool description to state these boundaries.
- Split the exact Runs 62–63 cross-project follow-up section out of measured run history into a `resume`-scoped module, preserving its indexed section hash and keeping it out of ordinary benchmark verification context.
