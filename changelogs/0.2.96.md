## Search-hit Jev selection

- `mssr_librarian_jev_select` optionally accepts up to 100 exact section/block handles already returned by `mssr_librarian_search`; no new tool or global index is added.
- MSSR revalidates each handle against the explicitly supplied Markdown snapshot, owner, source reference, privacy class, revision, exact range and fingerprint before sending any candidate to Jev. Duplicate, stale, malformed or out-of-scope handles fail before provider use.
- Jev receives bounded query-centered excerpts derived from the exact validated range, plus its parent heading path and range kind. Selection returns the same exact handle, and the caller must still exact-fetch before use. Calls without handles retain existing heading enumeration for compatibility.
- The selector remains advisory and unverified. Provider confidence remains uncalibrated; deterministic search remains candidate retrieval; no source authorization, truth, prose generation, verification, compaction or write authority is introduced.
- The always-loaded `## Architecture` core was narrowed to stable repository-wide invariants; context, lifecycle, consistency, architecture-impact, and Semantic Evidence details stay with their existing indexed modules and ADRs.
