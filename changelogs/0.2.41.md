## Changes

- Added `src/architecture-derived-graph.ts` with strict host-neutral import/call/dependency evidence. Edges must originate from an already-declared `authorityRef`/`impactRef`; nearby undeclared targets are normalized only as deduplicated `relationshipClass=derived` candidates with `promotionState=candidate` and `canonicalReviewEligible=false`.
- Added `src/architecture-invariants.ts` and optional canonical `.mssr/architecture-invariants.json`. Repositories may explicitly declare `require-edge` and `forbid-edge` invariants for an existing architecture without treating inferred graph structure as authority.
- Invariant observations distinguish `complete` from `partial` graph coverage. An observed matching edge can prove presence under either coverage mode; partial evidence never proves absence. Verified violations become REVIEW / `invariant-violation`, unresolved partial absence stays WATCH, and every evaluation fixes `canonicalRewriteAllowed=false`.
- Added strict JSON Schema parity for derived graph candidates, invariant manifests, invariant graph evidence, and invariant evaluations.
- Added the invariant manifest to the canonical `.mssr` project-control vocabulary and exported both C2f-C.5-D modules from the package public surface.
- MSSR self-hosts D: `architecture-impact-plane` deliberately declares the new D modules/schemas/manifest, `.mssr/architecture-structure.json` adds sparse selectors for `deriveArchitectureGraphCandidates`, invariant-manifest validation and invariant evaluation, and `.mssr/architecture-invariants.json` declares that portable Architecture Impact projection must not depend on Context Plane host I/O.
- Added `test:architecture-derived-invariants` and included it in the aggregate suite. Synthetic coverage proves non-widening candidates, strict promotion boundaries, complete/partial invariant semantics and schema parity; self-host coverage loads the real manifests and evaluates the declared no-host-dependency invariant.
- Updated ADR 0005, ROADMAP, PROJECT_CONTEXT and PROJECT_MEMORY to make the C2f-C.5-D ownership boundary durable. C2f-D bounded context feedback and C2f-E reviewed-current receipts remain separate pending gates.
- Source version moves to `0.2.41`. No new MCP tool, host queue, automatic architecture promotion, context request, or Bridge adoption is part of this release.
