## Evidence and Librarian ingress

- EvidenceAtom v2 records the evidence source class and canonical owner. `fresh` requires a host observation matching the exact normalized source ref, revision and owner, with an observation timestamp; unknown remains the safe default.
- Sensitive-excluded atoms are rejected, and atom attributes accept only compact identifier-like strings or scalar values. Librarian metadata rejects common free-form/private-content keys and strings over 240 characters; producer adapters remain responsible for typed, privacy-safe projections.
- Regression coverage verifies mismatched freshness observations, excluded attributes, metadata keys and size bounds.

## Jev host transport

- Added a portable decision-provider contract for bounded Jev requests and normalized responses, with exact question/answer key matching and type/range validation.
- Semantic curation, batch review, Project Context ref split and baseline verification all accept an injected provider. Injected providers keep credentials, endpoint selection, retry and logging policy at the host boundary.
- The existing TypeSafe client configuration remains as a deprecated compatibility fallback; hosts can migrate without a breaking release.

## Controlled benchmark handling

- Added `experiments/CONTROLLED_RUN_PROTOCOL.md` for immutable run manifests, source/corpus hashes, label provenance, held-out splits, support/uncertainty reporting and offline-by-default execution.
- Existing benchmark artifacts remain unchanged and archived separately. No external provider call or new paid benchmark run was performed for this release.

## Verification and adoption

- Full `npm run verify` passed, including the injected Jev transport regression, focused EvidenceAtom/Librarian coverage, cross-host conformance and read-only skill audit.
- Building or publishing 0.2.91 does not imply Bridge adoption or npm registry publication. Bridge remains on 0.2.89 until a separate controlled host adoption is performed.
