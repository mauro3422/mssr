## Changes

- Registered the same evaluator contract on native MSSR, Codex-local and OpenCode-local MCP servers and exported it from the package root.
- The tool returns only the existing advisory transition decision/candidate. It does not queue, persist, push, drain, display, attach TTL/history, execute recommendations, or grant authority; those remain host responsibilities.
- Added `scripts/test-operational-notice-contract.mjs` requiring identical tool schemas and identical results across all three hosts for opened, changed, escalated, deescalated, resolved, stable actionable suppression, quiet WATCH and explicit WATCH opt-in cases.
