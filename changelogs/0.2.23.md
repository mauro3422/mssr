## Changes

- Added `evaluateMssrConsistencyOperationalAttention`, a pure portable evaluator over semantic claim keys plus observer role, authority class, observation state, value/revision, required evidence, and lifecycle boundary.
- C2c distinguishes `canonical`, `replica`, and `historical` observations. A historical receipt can remain valid historical evidence while projecting `REVIEW` when its bounded claim no longer agrees with the current canonical fact; freshness and current consistency are explicitly orthogonal.
- Canonical authority disagreement projects `ERROR`. Replica mismatch normally projects `REVIEW`; required generated/installed/runtime disagreement at `pre-release`, `post-restart`, or `outcome` boundaries projects `ERROR`. Missing/unknown optional evidence remains quiet `WATCH`.
- Added role-aware advisory recovery actions for canonical inspection, source-replica inspection, generated rebuild, installed-package refresh, live-runtime verification, context revalidation, stale-claim review, and current-context replan. C2c never executes or authorizes those actions.
- Added the portable `mssr_consistency_evaluate` MCP tool to native, Codex, and OpenCode. All three hosts expose the same schema and are required by cross-host tests to return identical projections for identical bounded observations.
- Added focused fixtures for healthy release parity, the real stale executable pattern (`package/source=0.6.102`, `dist/live=0.6.101`), stale historical receipt claims, canonical conflict, missing baselines, unavailable required/optional evidence, revision drift, deterministic ordering, stable-state suppression, and resolution.
- Structured observations are intentionally bounded; raw prompts, transcripts, logs, private reasoning, secrets, or whole free-form memory documents are not accepted as C2c claim payloads. Semantic memory/context comparison requires an explicit bounded claim/revision rather than heuristic prose rewriting.
- Release metadata maintenance also corrected the root `CHANGELOG.md` compatibility pointer, which had remained on 0.2.14 while the canonical versioned history had advanced.
