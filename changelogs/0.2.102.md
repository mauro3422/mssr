## Read-only cited evidence pack

- Add `mssr_librarian_evidence_pack` for hosts to gather exact handles previously returned by deterministic search or selected by Jev/host policy. The host supplies current Markdown snapshots; MSSR re-fetches each handle and checks owner, source, caller-supplied privacy class, revision, range and fingerprint before returning text.
- Preserve source text unchanged and attach one citation record per range with handle id, owner, source ref, revision, range identity/kind, line span, fingerprint and privacy class. Duplicate handles/source identities, stale or mismatched handles, sensitive-excluded documents and over-budget requests fail closed.
- Bound the request to 16 documents/handles, 4,000,000 total source Markdown characters, 20,000 UTF-16 code units per exact range and 80,000 total returned text characters.
- Keep this tool separate from Jev selection, semantic relation/contradiction review and synthesis preview. It does not call Jev, generate or rewrite prose, verify truth, scan files, authenticate caller provenance or write canonical sources.
- Update ADR 0009, the Jev composition architecture module and project memory/state. The always-loaded PROJECT_CONTEXT authority was reviewed and requires no change.
