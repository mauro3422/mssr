## Changes

- Added `src/situation-context-feedback.ts`, a pure advisory projection over existing Situation/C2d output plus the project-context manifest.
- Feedback consumes only ready context-oriented C2d actions and their mismatch keys, then resolves the canonical Situation observation's explicit `sourceRef`; it does not inspect arbitrary prose or run a second semantic-selection pass.
- A canonical source mapping to exactly one manifest core/module yields `project-context-entry` with the existing source sections/topic/area and bounded `maxChars` as `suggestedMaxChars`.
- Explicit `#section` source selectors may disambiguate multiple modules sharing one authority file by matching manifest section headings. Without such evidence, shared-file mappings remain `ambiguous-authority`; unindexed sources remain `unindexed-authority`; missing canonical source identity is reported as unresolved. MSSR never guesses a module from filename alone.
- Integrated `contextFeedback` into `loadProjectContextHost` after Situation evaluation. Existing project-context selection occurs first and is unchanged; feedback never auto-loads the recommended entry or bypasses Context Plane budgets, permissions, or host choice.
- Added pure regression coverage for exact modules, shared PROJECT_MEMORY ambiguity, section-targeted PROJECT_STATE modules, unindexed authorities, missing canonical baselines, clean state and public API exposure.
- Added Context Plane host integration coverage proving stale delivered PROJECT_MEMORY produces REVIEW plus one exact feedback request while the suggested module remains absent from `projectContext.selected`.
- Updated ADR 0004, architecture, roadmap, project memory and canonical ownership to make the C2e-E ownership/abstention boundary durable.
