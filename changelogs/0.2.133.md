## Behavior

- Replace filesystem-path owner/source/project identifiers with request-local opaque labels, then scan the exact bounded request strings for private/non-public IPv4 addresses, remaining Windows/UNC paths, and common credential/token patterns immediately before provider invocation.
- Librarian selection returns `not-run` with safe category/count diagnostics when content is blocked. Semantic relation review rejects before starting any provider batch; all batches are screened first to avoid partial disclosure.
- Diagnostics never echo matched source text. Public IPv4 remains eligible.
- This is narrow deterministic defense in depth, not comprehensive DLP, authenticated privacy classification, or authorization. Host privacy labels and provider policy remain required.
