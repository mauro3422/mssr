## Changes

- Existing delivery receipts now refresh `sources`, `traceId`, and `nextGate` together with timestamp/fingerprint/count on re-selection.
- Durable receipts therefore represent the most recent evidence actually delivered for that message id, not merely the first source snapshot plus a newer counter.
- C2e Situation Model keeps only the newest receipt per canonical owner/ref, and evidence selected in the current load supersedes older receipts immediately.
- Added focused regression coverage proving receipt source revision/continuation refresh and clean stale-context resolution behavior.
- C2e remains revision-first and advisory-only: no free-form memory interpretation becomes canonical truth and no watcher action executes automatically.
