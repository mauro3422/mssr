## Librarian source-revision grouping

- `same-source-revision` now groups only records with the same namespace, kind, normalized source reference, revision, and payload fingerprint.
- Records for different sections of one Markdown document no longer become duplicate groups solely because they share the document source and revision.
- `same-payload`, `exact-record`, metadata, and identity-collision classifications remain separate deterministic signals. No semantic equivalence or canonical rewrite authority is added.
- Added a regression using multiple sections from one `Document Surface`; the existing positive source-revision alias fixture remains covered.
