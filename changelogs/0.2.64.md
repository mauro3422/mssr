# 0.2.64 — 2026-09-17

- Summary: reconcile Context Message canonical-owner drift when one project moves between filesystem paths without weakening cross-project isolation.
- Areas: context-plane, context-messages, inbox, canonical-ownership, history-recovery
- PROJECT_CONTEXT: reviewed-none
- PROJECT_MEMORY: reviewed-none
- PROJECT_STATE: updated

The compact PROJECT_CONTEXT and PROJECT_MEMORY roots were reviewed and remain accurate without expansion. The 0.2.64 migration detail lives in the indexed Context Plane history module and its segment metadata; PROJECT_STATE records the current release boundary.

Project-local Context Message inboxes may contain historical repository messages produced before the same canonical repository moved to another path, for example from `C:/Dev/mssr` to `D:/Dev/mssr`. Because the portable dedupe key intentionally includes `canonicalOwner`, the historical and current path could otherwise be selected together even when they describe the same ADR, PROJECT_* fact, changelog or incident.

MSSR now reconciles this drift inside the project-local Context Plane before current repository messages are enqueued. Reconciliation is evidence-gated: a historical pending message is superseded only when the current repository provider proves the same message id/kind and the same exact project evidence kind/ref/provenance identity while the canonical owner differs. Basename similarity, path similarity, or an unrelated repository with a matching directory name is never sufficient.

Historical delivery receipts remain immutable evidence of what a previous host actually delivered. The reconciliation changes only pending selection state; the current repository message is then enqueued normally under the current canonical owner. The host exposes bounded `reconciledOwners` metadata for observability.

Regression coverage proves both the positive path-migration case and fail-closed behavior for a different evidence ref. A live readback against this repository reconciled ten stale `C:/Dev/mssr` pending subjects and selected only `D:/Dev/mssr` evidence afterward.
