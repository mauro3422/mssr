# 0.2.43 — 2026-08-18

- Summary: Complete Situation Model C2f-E with strict metadata-only reviewed-current receipts so a host may remember an explicitly reviewed unchanged Architecture Impact case without editing canonical architecture, while every new, incomplete, stale or corrupt evidence state fails open to REVIEW.

- PROJECT_STATE: updated

## Changes

- Added `src/architecture-reviewed-current.ts` with portable receipt creation and evaluation semantics; hosts own persistence under ignored `.mssr/runtime/` and the portable layer performs no filesystem write.
- Receipt creation requires an explicit `reviewed-current` decision over complete active `possible-impact` evidence. Aligned or incomplete/unresolved evidence cannot create a receipt.
- Receipt identity binds architecture id, declaration fingerprint, reviewed baseline fingerprint, current authority revision, current source-set fingerprint, full projection fingerprint, review timestamp and an integrity fingerprint.
- Only an exact valid match yields `reviewed-current` / OK with `suppressRepeatedReview=true`. Missing receipt or incomplete evidence keeps REVIEW; declaration, baseline, authority, source-set or full projection changes invalidate the receipt and reopen review. A corrupt receipt fingerprint also fails open.
- Every evaluation fixes `canonicalRewriteAllowed=false`; receipts are metadata-only/advisory and cannot update ADRs, project context, architecture links or baselines.
- Added strict JSON Schema parity for receipt/evaluation objects, public exports, focused tests and aggregate-suite coverage.
- Added the C2f-E implementation/schemas to the declared Architecture Impact relationship and sparse structural map.
- Updated ROADMAP, ADR 0005, PROJECT_CONTEXT and PROJECT_MEMORY to close the C2f architecture-impact branch through reviewed-current receipt semantics.
- Verify-stage project-context selection exposed real size pressure in the accumulated Architecture Impact memory section (>3000 bytes). The current decision was extracted intact in meaning to `.mssr/knowledge/architecture/architecture-impact-review-decision.md` as a compact normal-routing module, while the full release-by-release timeline moved to separately indexed `architecture-impact-review-history.md` for debugging/history recovery; the old monolithic PROJECT_MEMORY section was removed instead of raising the selection cap.
- Roadmap/chat audit reconciled the original Architecture Impact Map v2 intent with the implemented code: C2f-C.5 and parent C2f are now explicitly closed because reverse lookup, Markdown anchors, AST symbol fingerprints, structural refinement, derived graph candidates, executable invariants, bounded context feedback and reviewed-current receipts all have concrete source/test owners. Automatic consumption at host edit/replan boundaries remains a separate pending Architecture Impact host-adoption gate; Bridge-local observations never become portable truth.
- Source version moves to `0.2.43`. No new MCP tool, host queue, Bridge adoption, automatic architecture mutation or canonical persistence is part of this release.
