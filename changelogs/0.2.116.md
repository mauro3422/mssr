## Behavior

- Keep the original list block and `block-N` identity intact; derive child list-item ranges with namespaced IDs such as `block-3/item-2`.
- Bind every derived handle to the current source revision, exact offsets/lines, and the item fingerprint. Search, Jev candidate validation, exact fetch, and cited evidence packs rebuild the same derived index; arbitrary narrowed offsets remain invalid.
- Preserve nested list and continuation lines inside their top-level parent item. Four-space-indented Markdown code is classified as code and does not produce list-item ranges.
- A fenced code block inside a list item closes only on a valid same-marker fence line with no trailing content, preventing code-like list markers from becoming phantom items.
- Confidence, authority, privacy, and canonical-write policy are unchanged. This release gate packages the portable source only; Bridge adoption, a live Jev run through the new implementation, npm publication, and installed-package attestation remain separate gates.
- Move the dated current-document and cross-repository Jev/Librarian development evaluations into separately indexed reference modules; keep their exact findings, provenance limits, and external frozen receipts, while reducing `PROJECT_STATE` to concise pointers.
