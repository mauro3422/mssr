# 0.2.132 - 2026-10-13

## Contract

- Summary: add an explicit round-robin ranking option for Librarian query variants to prevent alternate-language candidates from being starved by `maxResults`.
- Areas: Librarian retrieval API, query ranking, project context.
- PROJECT_CONTEXT: updated
- PROJECT_MEMORY: updated
- PROJECT_STATE: updated

## Behavior

- `queryVariantRanking` accepts `primary-first` or `round-robin`; omission preserves the established `primary-first` behavior.
- `round-robin` independently orders each query lane by exact-fetchability, that lane's lexical overlap, and deterministic tie-breakers, then interleaves distinct handles before truncation.
- Per-query scores are never combined. Results retain `queryMatches` / `scoreQueryIndex` and expose `rankingQueryIndex` in round-robin mode to explain the lane that placed the result.
- The mode remains opt-in. The exposed MyceliumFront replay is retrieval-only with provisional anchors; it does not validate Jev selection quality, answer sufficiency, or confidence.
