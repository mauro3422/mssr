## Why 0.2.79 exists

Two different local artifacts were produced under version `0.2.78`: Bridge adopted `pkg:0.2.78#3431c74d` (790532 bytes), while the isolated portable P7 release gate produced `pkg:0.2.78#d69d3f5d` (796923 bytes). They are not equivalent: the Bridge-adopted artifact lacks the portable `context-delivery-policy` and `document-context` modules, while it contains routing changes absent from the isolated P7 package. `0.2.79` is the explicit convergence release; the old byte identities remain evidence and are never overwritten or treated as interchangeable.

## Release identity invariant

A semantic version denotes one immutable package identity for adoption purposes. If two artifacts with the same version have different SHA-256 values, hosts must treat them as conflicting evidence, preserve both identities for diagnosis, and issue a new reconciled version. They must not overwrite the old artifact or claim byte-equivalent adoption from the version string alone.
