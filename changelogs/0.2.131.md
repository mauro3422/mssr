# 0.2.131 - 2026-10-13

## Contract

- Summary: exclude generated and caller-supplied metadata field names from Librarian lexical matches while preserving searchable metadata values and exact structured filters.
- Areas: Librarian retrieval
- PROJECT_CONTEXT: reviewed-none
- PROJECT_MEMORY: reviewed-none
- PROJECT_STATE: updated

## Behavior

- Lexical indexing reads metadata values but not object keys. Generated fields such as `revision`, `sourceRef`, and `startLine` cannot create candidates when those terms do not occur in document text or metadata values.
- Caller-supplied `searchableMetadata` values remain searchable; their keys remain exact-filter labels.
- Preserve primary-query-first ordering, explicit variant lineage, exact metadata filters, EvidenceAtom projection matches, and exact-fetch identity.
