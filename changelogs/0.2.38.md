## Changes

- Added `src/architecture-typescript-analyzer.ts` and exported `analyzeArchitectureTypeScriptSource(...)` from the package root.
- The analyzer consumes an existing C1 analysis plan plus host-supplied `sourceText` and `sourceRevision`; it performs no project filesystem discovery and does not widen reviewed architecture refs/selectors.
- TypeScript Compiler API loading is lazy and injectable. Importing MSSR core does not statically import TypeScript, and TypeScript remains outside mandatory runtime dependencies.
- The reference analyzer emits the existing strict C1 evidence schema and identifies both analyzer implementation and canonicalization scheme. The scheme is conservatively keyed by exact compiler version: `mssr-ts-symbol-v1:ts<version>`.
- Canonical fingerprints use TypeScript scanner token streams with trivia skipped and length-prefixed semantic tokens. Whitespace/comments do not change fingerprints; syntax/token changes do.
- `signature`, `body`, and `shape` are independent surfaces: callable headers exclude bodies; callable bodies exclude signatures; variable/property initializers are body evidence; class shape includes ordered member contracts while excluding method bodies/property initializers; interfaces/type aliases/enums support structural shape.
- Simple top-level functions/classes/interfaces/type aliases/enums/identifier variables plus qualified class/interface members are supported. Function/method overload signatures are fingerprinted as an ordered declaration set while body requires one implementation.
- Variable signatures preserve storage/modifier semantics (`const` / `let` / `var`, statement modifiers) independently from initializer bodies.
- Missing declared symbols return `missing`. Missing/invalid parser capability, syntax failure, unsupported/ambiguous aspects, missing implementation bodies, or oversized source return explicit `unavailable` evidence rather than guessed fingerprints.
- The repository self-hosts C2: `src/architecture-typescript-analyzer.ts` is a declared Architecture Impact Plane ref and `.mssr/architecture-structure.json` selects the fingerprint-scheme initializer and analyzer body as structural landmarks. Focused tests analyze these real selectors successfully.
- C2 does not compare structural evidence against a reviewed baseline, downgrade/upgrade `possible-impact`, emit notices, request context, persist receipts, infer import/call/dependency links, or rewrite architecture truth. C2f-C.5-C3 remains the owner of structural comparison/refinement policy.
- Added `test:architecture-typescript-analyzer` to the aggregate verification suite. No new MCP tool or Bridge adoption is introduced.
