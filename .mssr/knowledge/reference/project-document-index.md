# Project document index

This is a reviewed pointer index for durable project documents that should remain discoverable without being injected wholesale into normal Project Context payloads. A pointer establishes discoverability only for the stated role; the referenced repository document remains its own source.

- `docs/ARCHITECTURE.md` — broad current MSSR architecture overview: control/execution boundaries, components, Context Plane, adapters, lifecycle and observability. Use it when a task needs the full architectural narrative; selective `.mssr` modules remain the bounded operational/context surface.
